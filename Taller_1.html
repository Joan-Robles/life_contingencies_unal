Introducción

En este documento se calculan las primas de distintos seguros de vida y se elaboran algunas comparaciones.

Se emplean dos enfoques para calcular las primas: primero, se resuelve cada problema de forma analítica y se programa una función por producto; segundo, se programa una función con suficientes parámetros para calcular la prima de cualquier producto. Esta función calcula los valores esperados de forma explícita: vectorizando los componentes (descuento, pago y probabilidad) y resolviendo la sumatoria. Se hiceron pruebas unitarias para determinar que el resultado por ambas vías es el mismo.

Este documento constan de cinco secciones. Primero, esta introducción; segundo, una lista de datos y parámetros empleados; tercero, una sección sobre la lectura y procesamiento de datos; tercero —lo central del taller— el desarrollo algebráico de cada producto y la ejecución de las funciones específicas; cuarto, resultados general y comparaciones, y quinto, explicación de la organización del repositorio.

Este proyecto se realizó en R y está disponible en el siguiente repositorio de Github: life_contingencies_unal

Datos y parámetros

  • Tabla colombiana de mortalidad de asegurados 1998-2003. Extraída de la resolución 1555 DE 2010.
  • Tasa de crecimiento \(r\) del valor asegurado de 5.1%, correspondiente a la inflación. Se define así para mantener el poder adquisitivo del valor asegurado.
  • Tasa de interés técnica de 7.73%, correspondiente a la composición de interés real e inflación.

Punto 5

Prima de un seguro entero fraccionario con crecimiento del valor asegurado con patrón geométrico cada año.

La forma cerrada usada es:

\[ i^* = \frac{i-r}{1+r} \]

\[ P = \frac{i}{i^{(m)}}\cdot\frac{1}{1+r}\,A_x(i^*) \]

Comparación del crecimiento del valor asegurado: punto 2 vs punto 5

Se construye una sola gráfica para comparar el crecimiento del valor asegurado de los productos de los puntos 2 y 5 para un asegurado de 20 años.

horizon_years <- 5
time_grid <- seq(1 / m, horizon_years, by = 1 / m)

# Punto 2: crecimiento aritmético dentro de cada año, esquema tipo "b"
benefit_p2 <- 1 + r * (seq_along(time_grid) / m)

# Punto 5: crecimiento geométrico cada año, esquema tipo "a"
benefit_p5 <- rep((1 + r)^(0:(horizon_years - 1)), each = m)

plot(
  time_grid,
  benefit_p2,
  type = "l",
  lwd = 2,
  xlab = "Tiempo (años)",
  ylab = "Valor asegurado",
  main = "Comparación del crecimiento del valor asegurado"
)
lines(time_grid, benefit_p5, lwd = 2, lty = 2)
legend(
  "topleft",
  legend = c("Punto 2: aritmético intra-anual", "Punto 5: geométrico anual"),
  lty = c(1, 2),
  lwd = 2,
  bty = "n"
)

Organización del repositorio

La separación de archivos queda así:

  • general_functions.R: procesamiento de mortalidad y helpers generales.
  • life_ensurance.R: motor general de pricing y router por casos.
  • specific_functions.R: funciones cerradas para casos particulares.
  • Taller_1.Rmd: documento que explica, ejecuta y compara resultados, sin duplicar las funciones.

Con esta organización, cualquier corrección a una función se hace en un solo lugar y el reporte se actualiza al volver a ejecutar el .Rmd.
